# KILN 0.2.5

Hardware target: Teenage Engineering OP-XY, OS 1.2.1. Machine ID: `kiln`. The animated return meter, quiet-hit response and release behavior passed on the developer’s OP-XY. The standalone distribution packages that machine with its build dependencies.

Compared with 0.2.4, the display uses a logarithmic return-level scale and retains peaks between animation ticks. Quiet accents can launch the rider. Spall’s fractures move beneath the board while its horizontal position stays fixed.

Sixteen paired stereo renders across all eight modes produced sample-identical audio to 0.2.4. Five host tests exercise audio, level matching, Spall and rider behavior. The effect, display, screen and controls compiled for BF707. The TE Builder preparation check also passed with a 50-item selection and the 4 MiB profile. A measured hardware CPU percentage is unavailable for this release.

The source ZIP serves as both the GitHub repository tree and the TE Builder import. For a GitHub release, use the tag `v0.2.5`.
